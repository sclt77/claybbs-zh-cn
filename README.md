# ClayBBS 中文论坛系统

ClayBBS 是一套面向中文社区的论坛系统，适合搭建技术社区、兴趣社区、产品用户社区、会员交流社区和内容型网站。系统提供板块、主题、回复、用户、权限、授权、更新等常用论坛功能，并支持商业化发布和后续升级。

## 主要功能

- 板块管理：创建分类、板块和发布规则。
- 主题与回复：支持发帖、回帖、评论和内容管理。
- 用户系统：注册、登录、个人资料、权限分组。
- 后台管理：管理用户、板块、内容、系统设置。
- 安装向导：通过浏览器完成环境检测、数据库配置和管理员创建。
- 授权与更新：支持接入官方授权和版本更新服务。
- 商业发布：可配合授权服务和加密保护进行商业分发。

## 运行环境

建议环境：

- Linux 服务器
- Nginx 或 Apache
- PHP 8.1 或更高版本
- MySQL 5.7 / 8.0 或兼容数据库
- PDO MySQL 扩展
- OpenSSL 扩展
- Curl 扩展
- Zip 扩展
- Fileinfo 扩展

## 安装步骤

### 1. 上传程序

将程序文件上传到网站目录，并将域名绑定到该目录。

### 2. 设置目录权限

确保程序可以写入以下目录：

```text
config/
storage/
uploads/
```

如果目录不存在，请先创建。

### 3. 配置伪静态

Nginx 推荐配置：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

Apache 请确保已启用 `mod_rewrite`。

### 4. 创建数据库

在 MySQL 中创建数据库，并准备好：

- 数据库地址
- 数据库名
- 数据库用户名
- 数据库密码

### 5. 打开安装向导

访问你的域名，根据页面提示完成：

1. 环境检测
2. 授权验证
3. 数据库配置
4. 初始化数据
5. 创建管理员账号
6. 完成安装

### 6. 登录后台

安装完成后，使用管理员账号登录后台，配置站点名称、板块、用户权限和其他基础设置。

## 升级说明

升级前请务必：

1. 备份数据库。
2. 备份程序文件。
3. 备份上传文件。
4. 确认当前版本可以升级到目标版本。

升级时请保留：

```text
config/
storage/
uploads/
```

不要覆盖已有配置、用户上传文件和运行数据。

## 商业版本说明

如果你使用的是商业发行版本，可能需要安装配套的运行组件。请根据安装向导或官方文档提示完成环境检查和组件安装。

## 常见问题

### 安装页面打不开怎么办？

请检查 PHP 是否正常运行，域名是否绑定到正确目录，伪静态是否配置正确。

### 数据库连接失败怎么办？

请检查数据库地址、用户名、密码、端口和数据库权限。

### 上传图片失败怎么办？

请检查 `uploads/` 目录是否存在，并确认 PHP 有写入权限。

### 后台无法登录怎么办？

请检查管理员账号是否创建成功，服务器时间是否正常，浏览器 Cookie 是否被禁用。

## 安全建议

- 安装完成后删除或禁用不需要的安装入口。
- 定期备份数据库和上传文件。
- 使用 HTTPS。
- 定期更新 PHP 和服务器安全补丁。
- 不要公开数据库密码和后台账号。
